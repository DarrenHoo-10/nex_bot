## Scope

macOS terminal and file operations are supported. Stop kills the owned POSIX
process group, including shell descendants. Native window screenshot/click
automation remains Windows-only and is not advertised as available on Mac.

The external Hindsight service must be separately deployed/configured; no live
service was provisioned or migrated. Tests qualify the adapter against isolated
HTTP fixtures, not a particular remote deployment or paid model provider.
The independent native infrastructure fixtures remain separate from the app.

The Windows packaging configuration also excludes memory infrastructure, but
this run did not build or execute a Windows installer. Two physical machines,
cross-platform LAN routing and Intel Macs were not tested. Existing embedded
Windows memory databases require an explicit service-data migration before
connecting them through the new plugin; desktop updates do not delete them.
