## 助手操作

隔离 Core 使用合成记录验证重置生成新 ID、复制设置、重复请求幂等、已删除助手不可读和其他助手数据保留。6,000 条消息的回归在处理中制造写入错误，重启后从持久化进度继续。后台任务报告、金融历史映射以及远端附件重试均有覆盖。全程未在生产工作区创建、重置或删除测试助手。

## Core 验收

候选产物在 Mac Air 独立临时 Core 完成 120 条合成消息的分页、重置和删除任务状态验证。切换前确认无未结束任务并在主机私下备份数据和配置。首次切换最终候选时，公网资源请求返回 502，脚本自动回滚；再次切换后，本地和公网健康检查 200，未登录状态接口 401，HTML 和全部 7 个资源与构建字节一致。另从独立机器重复核对公网文件。6 个工作区的业务表哈希与停机备份一致。
