# NexAgent 图片预览与 0.9.51 全平台发布 — 2026-11-25

发布 [nexbot-v0.9.51-preview.1](https://github.com/DarrenHoo-10/nex_bot/releases/tag/nexbot-v0.9.51-preview.1)。Core、网页和四端安装包构建自已推送到 `main` 的 `8edb93c10a04b870ad5eefdee5402360ddc39697`。预推送通过 lint、TypeScript 和语言目录校验。

## 改动

- NexAgent 会话图片放在文字上方。有图和等待加载时保留同样大小的区域；桌面缩略图为 240 × 160。点缩略图放大，左上角关闭。
- 网页、Windows、Android 的 Core 图片预览复用按登录会话隔离的现有本地缓存。小于 2 MiB 的文件可以从上传所用的文件写入缓存，避免发送后立刻回读；缓存有上限，较大图片仍按需加载。Core 的加密图片存储、签名和权限逻辑未改。
- Apple 原生会话使用固定缩略图，离开主线程缩小图片，并用已加载的图片数据放大查看。
