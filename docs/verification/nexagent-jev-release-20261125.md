# NexAgent 翻译回退与 Token 用量简写 · 0.9.47 预览版

2026-11-25 发布。Core、Web 和四个平台的安装包均从 `main` 的 [`f48ed906`](https://github.com/DarrenHoo-10/nex_bot/commit/f48ed906774805d33df090e7497fa97585a11997) 构建。GitHub 预览版包含全部安装包、`SHA256SUMS.txt` 和 `SOURCE_COMMIT.txt`。[发布页](https://github.com/DarrenHoo-10/nex_bot/releases/tag/nexbot-v0.9.47-preview.1)

## Core 与 Web

- Jev 在原文显示后异步筛选正文，整条回复最多等待 5 秒。超时、失败或答案无效时用原有规则，第 11 次全局失败后停用 Jev 一小时。隔离测试覆盖回退、恢复和等待期间继续发送消息。上线后用合成文本经 Core 主机指定的代理调用 Jev，约 1.78 秒返回 HTTP 200。[翻译配置和开发验证](nexagent-translation.md)
- 没有新增数据库迁移。隔离 Core 启动、匿名访问返回 401 和全部 13 个静态资源验证通过。线上切换前备份了配置与六个工作区的数据，并校验备份哈希。首次切换时，设备重连刷新了有界的会话缓存，触发校验回滚。确认差异局限在缓存后重新部署，六个工作区的业务表摘要一致。公网 `/health` 返回 200，受保护接口返回 401，HTML 和 13 个静态资源与本地构建逐字节一致。
- 助手用量使用 `K`、`M`、`B`。示例 `82,620 → 82.6K`，`4,211,771 → 4.2M`，`4,200,000,000 → 4.2B`。
