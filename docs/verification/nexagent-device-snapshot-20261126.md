# NexAgent 完整设备列表推送 · Core 部署

发布提交 `06e1a4e06ef0ae6533db721b22d6a0faa7aad6ec`。手机端新建会话已选定工作目录时，另一台电脑连接状态变化会触发设备列表更新。旧 Core 仅在更新中发送发生变化的电脑。客户端将设备字段应用为完整列表，已选电脑因而从列表中消失，界面显示「电脑离线」。

Core 在设备状态更新和撤销事件中发送与初始快照一致的完整设备列表。会话更新仍按变化项推送。现有客户端通过原有协议接收完整列表。

## 验收

- 在隔离环境运行此前的生产 Core，模拟两台真实握手的设备和一个 Android 使用的 Bearer 认证流。另一台设备断开后，旧快照确实遗漏仍在线的已选电脑。新 Core 在同样的断开和撤销过程中保留已选电脑和在线状态。
- 17 项设备流相关测试通过，覆盖重新连接、鉴权和双设备状态投递。[发布提交 CI](https://github.com/DarrenHoo-10/nex_bot/actions/runs/45742416169)
- Mac Air 上的 6 份 SQLite 备份通过完整性检查。切换时备份工作区和配置，切换前后业务数据哈希一致。生产健康检查为 200，匿名 API 为 401，首页和 24 项前端资源与构建工件一致。
- 线上复查 Windows 客户端 0.9.55 仍在运行，Core 收到设备重新连接。Android 场景通过隔离设备流验收，用户手机的实际显示留待实机复核。
