生产 Core、网页和四端安装包均来自主分支提交 `c7cbef97fdf7f77fdfd586609f0ef8370d79e8ba`。功能提交为 `0faf56c6`，发布前修正了 Android 二进制预览读取、旧图片读取兼容性和结论的助手名称。[GitHub 预览版](https://github.com/DarrenHoo-10/nex_bot/releases/tag/nexbot-v0.9.57-preview.1)

## 功能验收

- 隔离的打包执行器从历史记录中发现测试图片。仅读取会话文字时，通信中没有图片字节，模拟的私有对象存储中也没有新增对象。首次并发打开预览时，3072 像素的合成 PNG 转为更小的 WebP，两次请求共用一份加密对象。断开来源设备后仍能取得相同内容。旧图片地址与压缩预览分别返回原有格式和 WebP。
- 在独立 Electron 用户目录对网页预览做了实际重载验证。首次只请求一次压缩图，之后让图片接口离线，重载依然从 IndexedDB 显示图片。Android 核心测试覆盖重新打开后读取私有磁盘缓存，以及登出后拒绝缓存访问。
- 界面回归覆盖进行中的消息、结束后展示结论、从「更多内容」展开过程、过程里没有复制按钮和结论保留复制操作。连续的「上下文已压缩」合并为一条，分别发生的压缩仍然可见。
- 输入框的技能选择器可以按名称和描述模糊搜索，所有助手共享技能。隔离 Core 验证了登录用户取得技能列表及匿名请求返回 401。

首次主线 CI 的 5 条断言涉及旧图片地址以及过程折叠后的界面预期。发布前已修正读取兼容性、助手标识和测试夹具，提交 `846b9493` 进一步将复制和分支的回归用例改为先点开「更多内容」。相关测试均已在本机重新通过。Android 远端构建曾因 Gradle 插件仓库无法解析 Kotlin 插件中断，本机完整构建及测试通过。
