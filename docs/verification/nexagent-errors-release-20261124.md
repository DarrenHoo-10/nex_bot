# NexAgent 发送体验、可读错误与模型失败提醒发布验收（2026-11-24）

发布 [nexbot-v0.9.45-preview.1](https://github.com/DarrenHoo-10/nex_bot/releases/tag/nexbot-v0.9.45-preview.1)，客户端构建自 `main` 的 [924bdaee](https://github.com/DarrenHoo-10/nex_bot/commit/924bdaee7f8f0500b914bc0d8431b1c25b20ee76)（只比 Core 部署的 [3b6a8015](https://github.com/DarrenHoo-10/nex_bot/commit/3b6a8015015085ca397a71a8592063fdbbd85b18) 多了版本号）。推送前合并后的代码通过 lint、两项 TypeScript 检查和语言包检查。

## 改动

- 发送：消息和等待动画立即出现，输入框立即清空，失败时放回。等待动画下不再有说明文字和「打开远程终端」，用户消息上方不再有「你 时间」。
- 「排队 / 引导」只在 Agent 运行中且输入框有内容时出现。
- 编辑并重发：只对 30 秒内、尚无回应的消息提供。原消息移出对话，文字和本页发出的附件回到输入框，无提示条；清空输入框即放弃。重发时若 Agent 仍在处理原消息，先中断再直接发送。
- 手机宽度下会话标题栏单行，分享与列表按钮在右上角。
- `/model` 等命令留下的记录不再显示为用户消息（电脑端解析器、网页、Apple 三处）。
- 模型调用最终失败：居中弹窗说明原因，对话里只有一行中文说明（网页与 Apple）。Claude Code 自身的重试次数按要求未改。
- 网页的请求错误：代理返回的 HTML 错误页、网络失败和浏览器原始报错一律换成简短中文；Apple 端按状态码给出相同文案。
- 只填域名的 OpenAI 格式模型地址自动在 `/v1` 下请求（对话、翻译、模型列表、记忆网关），翻译失败在 Core 日志记录供应商状态码。

## 问题来源

- 设置页的「Failed to execute 'json'…」：另一会话在 11-23 23:22–23:26 部署 Core，期间中转返回 nginx 的 HTML 502 页，前端把它当 JSON 解析。
- 翻译总失败：线上所选连接的地址是不带 `/v1` 的域名，该网关在 `/chat/completions` 上返回 502，`/v1/chat/completions` 才是正确路径。修复前的 63 次翻译请求中 57 次在约 0.2 秒内失败。
- 消息等待十几分钟：消息 1 秒内送到电脑上的 Claude，Claude Code 调用模型供应商时连续收到 429（额度用完），重试约 10 分钟后才报错。
