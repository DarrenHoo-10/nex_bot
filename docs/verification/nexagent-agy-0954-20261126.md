## 会话验证

- NexAgent 在任务电脑上通过 `agy acp` 新建或续接 Antigravity 会话。运行中的外部终端会话可在 NexAgent 查看记录，退出终端后可按原会话 ID 续接。执行器沿用 Windows 用户已配置的本机代理连接 AGY。
- Windows 官方 AGY 1.5.17 在隔离项目中完成 CLI → NexAgent 执行器 → CLI 往返。确认模型目录可读，同一会话 ID 下的实际模型回复保留了前文，CLI 也读到了执行器发送的消息。
- 隔离 Core 使用打包后的执行器验证新建、续接、审批、发送去重和队列顺序。回归覆盖旧轮次事件先到、本轮先于发送回执结束，以及既有终端会话的队列顺序。
- 提交前的 lint、类型和 10 种语言校验通过。发布准备中 7 个相关测试文件有 230 项通过，依赖真实 herdr-core 的测试未启用。Web UI 的 42 个测试文件共 457 项通过。

## 工件与生产验证

- Windows 用实际 Setup 安装、自选目录和覆盖升级，并在已安装的程序中通过 20 项登录及设备链路冒烟。下载工件的摘要与构建验收日志一致。[Windows 构建与验收](https://github.com/DarrenHoo-10/nex_bot/actions/runs/45677158479)
- Android 使用 JDK 17 和 SDK 36 构建，核对了 APK 的包名、版本与调试签名。签名证书与上版一致。
- Apple 在隔离克隆与专用模拟器中完成 macOS、iOS 模拟器和 iPhone 构建。NexClientKit 的 274 项测试通过。核对 DMG 版本、应用签名和内嵌设备执行器，以及 IPA 的版本、主程序和未签名状态。
- Mac Air 上对 6 份数据库的 SQLite 备份执行 `quick_check`，确认 schema 59。隔离候选通过后，在无活动任务时完成生产备份和切换，前后业务表哈希一致。公网与本机健康检查均为 200，匿名 API 与 WebSocket 为 401，首页及 24 项静态资源与构建产物逐字节一致。
- 发布提交的 CI 全部通过。Core、Web UI 和共享协议共通过 2184 项测试，10 项按条件跳过。Android 测试与协议样例校验通过。[发布提交 CI](https://github.com/DarrenHoo-10/nex_bot/actions/runs/45677053177)
