# NexAgent 权限确认送达各端、新会话默认完全访问：全平台发布 0.9.46（2026-11-24）

发布 [nexbot-v0.9.46-preview.1](https://github.com/DarrenHoo-10/nex_bot/releases/tag/nexbot-v0.9.46-preview.1)。Core 与全部客户端构建自 `main` 的 [75129874](https://github.com/DarrenHoo-10/nex_bot/commit/7512987436bf2e959ab4b4d87c19fdf2dc871955)：在 [6a735995](https://github.com/DarrenHoo-10/nex_bot/commit/6a735995d403b8b1fc5b11e8c2a7933f1c0089a9) 之上只改了版本号。功能改动及开发期验证见 [NexAgent 权限确认](nexagent-permission-prompts-20261124.md)。推送前在该提交上通过了 lint、TypeScript 检查和语言包检查。按发版规则，发布阶段不运行测试套件。

## 改动

- Claude 和 Codex 需要确认时，网页、Windows、Android、Mac 和 iPhone 都会显示权限卡片。卡片可展开查看完整参数，命令行支持时还有「本会话总是允许」。
- Windows 上的 Claude 钩子改由 PowerShell 运行，没有 Git Bash 时也不再直接拒绝。与 Core 的连接断开后，未处理的请求会在重连时重新送达。
- 没有钩子上报的确认对话框（Codex 终端界面，或没有钩子的 Claude 终端）会从屏幕上读出并显示为卡片，只在该对话框仍在屏幕上时代为作答。
- 新建会话和分叉默认以完全访问启动，新建会话页可改为「每次询问」；继续已有会话时沿用命令行自身的设置。权限模式只发给声明支持 `permissions` 的电脑端。

## Core

- 本次没有数据迁移：源码改动不涉及迁移，新旧版本的 8 个 schema 文件逐字节相同。服务端依赖与上一版一致，以覆盖包方式部署 `core`、`ui`、`package.json` 和 `SOURCE_COMMIT`，暂存时逐一核对了 59 个文件的哈希。
- 隔离候选 Core（合成数据）检查通过：健康检查 200，未登录访问返回 401，携带令牌访问返回 200，首页和 13 个资源与本地构建逐字节一致，并包含新的权限界面文案。
- Mac Air 从 `main-3b6a8015-20261124` 切换到 `main-75129874-20261124`：等到没有进行中的任务后，备份数据与配置并核对哈希。切换前后 6 个工作区的业务数据摘要一致，本地和公网各 13 个资源逐字节一致。
- 从本机经公网复核：健康检查 200，未登录状态接口 401，首页与 13 个资源和本地构建一致。
