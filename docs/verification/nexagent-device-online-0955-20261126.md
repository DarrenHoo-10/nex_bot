# NexAgent 设备离线误报 · 0.9.55 四端预览发布

生产 Core 和四端安装包均来自已推送到主分支的提交 `0b6961857e85c295f5137da3bc5f1fae6d74dc30`。[预览版与校验文件](https://github.com/DarrenHoo-10/nex_bot/releases/tag/nexbot-v0.9.55-preview.1)

## 复现与修复

现场排查时，Windows 客户端的登录和设备连接正常，NexAgent 能读取本机目录。代码和隔离回归定位到新建会话页的两条误报路径。

- 页面比设备列表先完成初始化时，新建会话会保留空的设备选择。现在会显示「等待电脑连接」，设备出现后补选并保留草稿。
- Web 目录选择器过去会把运行工具未就绪的在线设备标成离线。现在依据设备连接状态显示，选中在线电脑后会提示具体的运行工具阻塞原因。Apple 客户端也会在设备列表到达后补选设备。
- Web 新建会话和会话状态的相关回归合计 82 项通过。发布提交的全量检查发现一条先前主分支已失败的复制按钮测试。`aca33149` 同步测试夹具后，105 项相关回归通过，主分支 CI 复核通过 2188 项测试，10 项按条件跳过。[发布提交检查](https://github.com/DarrenHoo-10/nex_bot/actions/runs/45736187264) · [主分支复核](https://github.com/DarrenHoo-10/nex_bot/actions/runs/45738789545)
