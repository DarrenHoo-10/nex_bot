# Assistant character artwork

User-approved generated character atlases for the five assistant appearances:
deepseek (blue-maid), claude (orange-flower), gpt (white-dragon),
gemini (purple-cat), grok (gold-bat). Names identify the appearance, not the
model connected to an assistant.

`blue-q/*-alpha.png` contains the approved blue character action sheets with
their backgrounds removed. `cast/idle.png` and the four action sheets contain
the other characters. No remote image URLs, account data or credentials are
needed to render them. Web and native clients package the same source images.

These are discrete illustrated poses with brief transitions, not skeletal or
continuous video animation. Random idle gestures are disabled in the product;
only idle blinking and actual task-state poses are enabled.
