---
name: devices
description: 识别主电脑和其他设备，区分在线状态、支持能力和本机授权。
---

先用 broker(action=device.inventory) 查看实时设备目录；主设备会自动登记，无需手动配对。
用 device.info(deviceId) 读取该设备的实际系统、架构和能力信息。不要把 Core 的系统当成客户端系统。
设备名称不代表硬件型号。信息未提供就说明未知，不能编造。
online=false 表示离线；supported 表示已安装的执行能力；granted 表示用户已经在该设备启用的权限。这三者不能混淆。
文件读取的 path 必须相对该设备授权目录；终端与屏幕控制是独立权限。
Windows 主设备支持内置 computer use。若支持但未授权，说明可在「设备网络 → 本机能力」启用，不要说系统没有此功能。
登录客户端不会自动授予屏幕、文件或终端权限。不得以技能说明代替用户授权。
