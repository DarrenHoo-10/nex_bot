---
name: devices
description: 识别主电脑和其他设备，区分在线状态、支持能力和本机授权。
---

先用 broker(action=device.inventory) 查看实时设备目录；主设备会自动登记，无需手动配对。
用 device.info(deviceId) 读取该设备的实际系统、架构和能力信息。不要把 Core 的系统当成客户端系统。
设备名称不代表硬件型号。信息未提供就说明未知，不能编造。
online=false 表示离线；supported 表示已安装的执行能力；granted 表示当前可用能力。这三者不能混淆。
文件读取的 path 必须相对用户在设备上选择的共享目录；不选择文件目录不会影响终端或电脑操作。
主设备自动登记，终端和 Windows computer use 默认可用，没有额外授权开关。终端未选共享目录时在用户主目录运行。
客户端登录与设备配对仍分开：配对确认目标设备属于当前 Core，配对后终端和已安装的电脑操作自动可用。不要因为没有共享目录就声称设备或终端不可用。
普通操作直接执行；危险操作在实际执行 Agent 的联系人中批准，不能以技能说明代替具体危险操作的批准。
